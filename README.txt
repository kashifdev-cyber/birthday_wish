# Open When… — For My Brother

Open `index.html` in any modern browser (works offline except Google Fonts, which fall back gracefully).

EDIT: near the top of index.html, change
  const CONFIG={brother:"Brother",from:"Your sibling"};
to his name and yours. Letter texts live in the `letters` object further down.

Features: tap-to-open gift screen, confetti, 5 "Open When" letters with progress counter,
photo scrapbook with zoom, "why you're the best" cards, black/gold finale with Celebrate + Replay.
